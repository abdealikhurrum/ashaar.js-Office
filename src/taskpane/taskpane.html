    What's a zine fold? A zine (rhymes with "bean") is a small, DIY, folded booklet — this option turns the document into one from a single sheet of paper, with a few folds and one short cut, no stapler needed. Every sheet becomes its own separate little booklet. Prints single-sided — the double-sided controls above don't apply here.

    Styles

    Named Word styles for prose documents — headings, emphasis, block quotes, and Quran quotes — grouped by use case. Requires desktop Word (Windows/Mac).

    This add-in's Styles tab requires desktop Word (Windows or Mac) — it isn't available on Word for the web.

    RTL document setup

    Creates an Ashaar Normal body style (right-aligned, complex-script font/size) — apply it to body paragraphs from Word's Styles gallery — right-aligns footnote text, and sets right-to-left section layout. The add-in API cannot set true paragraph reading order or move the footnote separator line (VBA/UI-only): for perfect bidi use Word's Layout → Paragraph Direction, and to move the separator use Draft view → Show Notes → Footnote Separator (or the downloadable template).
