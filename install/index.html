Install Ashaar Poetry for Word

One-time setup. Pick your operating system.

Easiest — download & open

  1. Download installer
  2. In Downloads, right-click the file → Open → Open (needed the first time so macOS allows it).
  3. It closes Word, installs the pane, and reopens Word. Done.

Open the pane from Home ▸ Add-ins ▸ Ashaar Poetry.

— or, if that's blocked —

Paste one line into Terminal

Open Terminal (press ⌘-Space, type “Terminal”), paste this, press Return:

mkdir -p ~/Library/Containers/com.microsoft.Word/Data/Documents/wef && curl -fsSL "https://abdealikhurrum.github.io/ashaar.js-Office/manifest.prod.xml" -o ~/Library/Containers/com.microsoft.Word/Data/Documents/wef/a03d69e0-06d9-47c9-8995-06d3bdb5b197.manifest.xml && rm -rf ~/Library/Containers/com.microsoft.Word/Data/Library/Caches/* && echo "Done — quit Word (Cmd+Q) and reopen it."

Easiest — download & run

  1. Download installer
  2. Double-click the downloaded file. If Windows shows “Windows protected your PC”, click More info ▸ Run anyway.
  3. Click Yes when asked for administrator permission (needed to register the add-in).
  4. Open Word → Insert ▸ Add-ins ▸ My Add-ins ▸ Shared Folder → pick Ashaar Poetry.
— or, if that's blocked —

Run in PowerShell

Click Start, type “PowerShell”, right-click it → Run as administrator, paste this, press Enter:

iwr 'https://abdealikhurrum.github.io/ashaar.js-Office/install/Install-Ashaar.ps1' -UseBasicParsing | iex

Then restart Word and open it from the Shared Folder tab under My Add-ins.
